# Spec marks

Bundled SVG artwork for the five document notations. No runtime requests to third-party sites.
Downloaded 2026-10-25. Marks identify compatible formats; no endorsement is implied. Trademarks remain
with their owners. Preserve artwork rather than redrawing a brand with UI icons.

| Format | Source | License / treatment |
| --- | --- | --- |
| Gherkin | [Cucumber mark, Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/cucumber.svg) | CC0; original monochrome SVG. Gherkin is Cucumber's language. |
| Quint | [Quint's official editor mark](https://github.com/quint-co/quint/blob/main/vscode/quint-vscode/icons/logo-dark.svg) | Apache-2.0; original SVG and colors. |
| DMN | [Camunda Modeler DMN format mark](https://github.com/camunda/camunda-modeler/blob/develop/client/resources/icons/file-types/DMN.svg) | MIT; added the SVG namespace so it works as an image. |
| Alloy | [File Icons Alloy mark](https://github.com/file-icons/icons/blob/master/svg/Alloy.svg) | ISC; added a viewBox matching its original 512 × 512 coordinates. File Icons associates it with `.als`, the formal language, not other products named Alloy. |
| OpenSLO | [OpenSLO's official mark](https://github.com/OpenSLO/OpenSLO/blob/main/website/docs/assets/images/logo2.svg) | Apache-2.0; original SVG and colors. |

DMN uses the recognizable decision-table mark from its modeling ecosystem. The official
[OMG page](https://www.omg.org/dmn/) publishes a raster logo; no verified official SVG was found.
This asset is a notation mark, not a claim that Camunda's mark is the OMG standard's official logo.
Statecharts cover multiple notations and retain their existing named navigation rather than being
assigned an unrelated vendor logo.

License texts are alongside these files: APACHE-2.0.txt (Quint and OpenSLO), CAMUNDA-MIT.txt,
FILE-ICONS-ISC.txt and SIMPLE-ICONS-CC0.txt. To update a mark, retrieve the source above, inspect the
SVG for active content or external references, preserve attribution, and verify the rendered asset.
